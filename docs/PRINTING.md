# 打印与 PDF 指南

## 默认目标

打印面板默认启用：

```text
单版本 1 页 / 多版本最多 2 页（推荐）
```

含义如下：

- 一首歌只输出一个版本时，尽量在一个物理页面内完成；
- 一首歌输出多个版本时，先尝试全部放在一页，确实放不下时最多使用两页；
- 短歌会自动增大字体，以更充分地利用页面；
- 长歌会依次尝试压缩多余空行、用 `/` 合并连续短句、双栏和更紧凑的标题信息；
- 最终排版通过浏览器真实高度测量，不截断歌词。

## 两种分页策略

### 严格页数模式

适合演唱会现场携带、A5 小册和希望控制总页数的情况。

可能出现的取舍：非常长的歌曲、完整外语原文加长篇翻译，或多个超长版本同时输出时，为满足页数上限，字号会缩小。

### 可读性优先

适合收藏版和屏幕阅读。字体不会为了页数上限无限缩小，必要时允许续页。

## 字体放大逻辑

程序不是按固定字号输出，而是为每首歌分别测量：

1. 从较大的候选字号开始；
2. 检查标题、版本标签、歌词和页脚是否完整落在页面内；
3. 若溢出，使用二分搜索逐步减小；
4. 选取不溢出的最大字号；
5. 短歌因内容少，会自然得到更大的字号。

因此，同一本 PDF 中不同歌曲的字号可能略有不同，这是为了同时满足“尽可能大”和“不超过页数”的要求。

## 短句合并

连续的短行可以打印为：

```text
第一句 / 第二句 / 第三句
```

但以下内容会尽量保持独立：

- `[Verse]`、`[Chorus]` 等段落标记；
- “主歌”“副歌”“Bridge”“间奏”等结构标题；
- 空行形成的明确段落边界；
- 原文与翻译逐行对照关系。

打印优化只作用于临时排版副本，不会修改编辑器中的原始歌词。

## 双栏

当单栏无法以合适字号装入页面时，程序可使用两栏：

```text
左栏前半段 → 右栏后半段
```

阅读顺序是先读完左栏，再读右栏。对于严格逐行双语对照，会优先保留语言对照，不会把一行原文和对应译文拆散。

## 多版本

打印窗口提供：

- 每首仅默认版本；
- 当前歌曲使用当前版本，其余使用默认版本；
- 每首输出全部版本。

全部版本输出时，同一首歌仍是一个章节：

- 能放下一页：所有版本同页；
- 放不下一页：同一歌曲连续使用第 1、2 页；
- 不会在目录中重复建立多个同名曲目。

## 双语布局

- **自动**：A4 优先左右对照，A5/小册优先上下分区，并根据实际高度切换。
- **左右对照**：原文与译文并排。
- **上下分区**：先原文，后翻译。
- **逐行对应**：适合原文与翻译行数一一匹配的版本。

## A4 阅读版

建议系统打印设置：

```text
纸张：A4
方向：纵向
边距：默认或无
缩放：100% / 实际尺寸
背景图形：开启
```

## A5 单页版

适合使用 A5 纸直接打印，或保存为较小页面的 PDF。

```text
纸张：A5
方向：纵向
缩放：100% / 实际尺寸
背景图形：开启
```

## A4 对折小册

网页会把 A5 逻辑页自动拼成横向 A4 印刷面。建议：

```text
纸张：A4
双面：开启
翻转：短边翻转
缩放：100% / 实际尺寸
背景图形：开启
```

不同打印机驱动对“长边/短边”的定义可能不同。正式打印前，应先输出 4 个逻辑页做测试，确认折叠后页码顺序和正反方向。

## 目录和封面

严格控制页数时，可以关闭：

- 封面；
- 目录；
- 尚未导入歌词的曲目；
- 版本与核实说明。

歌曲本身的“一页/两页”限制不包含整本歌词本的封面、目录和版权页。

## 发现内容过小怎么办

1. 只打印默认版本；
2. 外语歌只保留需要的翻译版本；
3. 选择 A4 而不是 A5；
4. 改为“可读性优先”；
5. 检查歌词中是否存在大量无意义空行；
6. 把不需要现场阅读的重复段落建立为另一个收藏版本，而不是默认现场版本。
