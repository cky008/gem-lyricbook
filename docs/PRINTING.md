# 打印与 PDF 指南

## 打印范围与排序

三个概念彼此独立：

- **筛选**：只改变网页左侧此刻显示哪些歌曲；
- **演出歌单**：定义 Part、Encore、候选章节和歌曲顺序；
- **打印范围**：决定本次 PDF 实际输出什么。

打印范围包括：

1. 当前歌曲；
2. 仅当前演出歌单；
3. 当前目录筛选结果；
4. 全部曲目库。

选择“仅当前演出歌单”时，会忽略搜索和标签筛选，严格按当前歌单顺序输出。可选章节可以通过“包含歌单中的可选章节”开关统一包含或排除。

## 默认分页目标

默认使用：

```text
单版本 1 页 / 多版本最多 2 页（推荐）
```

程序会为每首歌分别测量：

1. 清理仅影响排版的多余空行；
2. 尝试保留原始换行；
3. 必要时把连续短句合并为 `第一句 / 第二句`；
4. 尝试单栏、双栏、双语左右或上下布局；
5. 二分搜索可完整容纳的最大字号；
6. 最终打印前再次在完整文档中检查页面、正文安全区和页码区域；
7. 若字体栅格化造成轻微越界，自动小幅回退字号；仍无法安全容纳时阻止打印并提示页码。

排版优化不会修改本地保存的原始歌词。

## 单版本与多版本标题

- 一首歌只保存一个有内容版本时，不打印“默认版”；
- 一首歌保存多个版本时，即使本次只输出默认版本，也会显示“国语”“粤语”“现场版”等版本名；
- 原文与中文翻译属于同一个歌词版本。

## 目录

目录采用候选筛选加真实 DOM 测量，不以固定容量直接决定分页：

1. 权重模型先快速排列单栏宽松、双栏标准和紧凑版式候选；
2. 浏览器把完整目录放进最终 A4 或 A5 打印页，测量标题、说明、章节、条目、栏宽、页面高宽和页脚安全距离；
3. 只要某个完整候选安全，就保留单个目录页；
4. 只有全部完整候选都不安全时，才在最紧凑版式中二分寻找当前页能够容纳的最大章节／歌曲前缀；
5. 分页完成后重新计算歌曲页码，并复检条目唯一性、顺序和内部链接。

当前回归基准：

- 约 34 首的演出主流程：A4 使用单栏和较大字号，完整放入 1 页；
- 同一主流程：A5 和 A4 对折也只占 1 个 A5 逻辑页；
- 包含全部可选章节的 72 首歌单：A4 使用双栏 `standard`，A5 与 A4 对折逻辑页使用双栏 `compact`，三种版式都只占 1 个目录页；
- 真正超大的目录才产生“（续）”，每页必须使用可安全容纳的最大前缀，不允许稀疏续页或隐藏溢出；
- 全部曲目库可继续分为“当前演出歌单”和“候选与其他曲目”两个逻辑部分。

电子 PDF 中的歌名带内部链接，支持的阅读器可点击跳转到对应歌词页。A4 对折 PDF 的一张物理页面会同时展示两个 A5 逻辑页；目录与版权页可能出现在同一张纸的左右两侧，但这不等于目录被拆成两页。

## A4 阅读版

```text
纸张：A4
方向：纵向
缩放：100% / 实际尺寸
背景图形：开启
```

## A5 单页版

```text
纸张：A5
方向：纵向
缩放：100% / 实际尺寸
背景图形：开启
```

## A4 对折小册

对折版生成的是**已经完成小册拼版的横向 A4 印刷面**，不是普通顺序的 A5 页面。

假设有 8 个逻辑页，PDF 印刷面顺序为：

```text
第 1 张纸正面：8 | 1
第 1 张纸背面：2 | 7
第 2 张纸正面：6 | 3
第 2 张纸背面：4 | 5
```

打印设置：

```text
纸张：A4
方向：横向
双面打印：开启
翻转：短边翻转
每张页数：1
缩放：100% / 实际尺寸
背景图形：开启
```

不要再次选择“每张 2 页”或打印机自带的“小册子／Booklet”，因为网页已经完成双页拼版。打印后保持纸张顺序，整叠从中线对折，在折线处用长臂订书机钉两枚骑马钉。

打印窗口会显示第一张纸的正反面页码预览，并提示逻辑页数、补白页数和预计双面 A4 张数。

## 发现字体太小

可依次尝试：

1. 只输出默认版本；
2. 关闭点歌和惊喜候选章节；
3. 改用 A4；
4. 关闭不需要的版本说明；
5. 切换“可读性优先”，允许续页。
