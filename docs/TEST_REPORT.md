# v5.1.2 自适应目录、打印与移动端回归测试报告

测试日期：2026-08-31

## 变更范围

v5.1.2 只重写打印目录的栏数、密度与分页模型，并补充对应调试信息；歌曲正文的字号搜索、单双栏选择、双语布局、页码安全区和小册拼版逻辑沿用 v5.1.1。

重点回归目标：

- 34 首、5 个 Part 的深圳主流程目录在 A4、A5、A4 对折中都只占 1 个逻辑目录页；
- 目录不再固定使用 A4 三栏；
- 全曲库目录标题换行必须计入容量，避免最后一项被挤入页脚；
- 目录歌名继续保留 PDF 内部链接；
- v5.1.1 的 iOS 侧栏／Modal 滚动锁修复不得回归；
- 用户 v4 备份与多版本数据继续可导入。

## 测试数据与隐私

## iOS 窄屏滚动锁回归

测试环境：390 × 844、触控模式、iPhone Safari User-Agent 的 Chromium 移动仿真。

### 正常路径

```text
打开侧栏 → 点击演出歌单／排序 → 侧栏自动关闭
→ 关闭 Modal → 主页面继续滚动
```

### 旧 Bug 对抗路径

```text
侧栏保持打开 → 直接打开排序 Modal
→ 先关闭侧栏 → 再关闭 Modal → 主页面继续滚动
```

两条路径均满足：

- `body.style.overflow` 为空；
- `html.style.overflow` 为空；
- `modal-open` 已移除；
- 侧栏已关闭；
- 可见 Modal 数量为 0；
- backdrop 数量为 0；
- 页面可继续上下滚动；
- 控制台错误为 0。

## 歌曲正文回归依据

v5.1.2 未修改歌曲正文拟合函数、页码安全区、版本标题规则或小册拼版函数。v5.1.1 已使用同一份真实私人备份完成 A4、A5、A4 对折的全曲库、全部版本回归，结果均为 0 个溢出页、0 个单版本“默认版”误显示。v5.1.2 的代码差异只触及目录模块、目录样式、版本号和调试输出，因此正文结果沿用该回归基线，同时重新执行了本报告中的目录 PDF 与 iOS 回归。

## 结论

v5.1.2 满足本次发布条件：34 首主流程目录在三种版式中均保持单页；A4 不再浪费为固定三栏；A5 和对折不再产生空旷续页；目录链接、iOS 滚动恢复、旧备份兼容和公开数据隔离均通过验证。

真实 iPhone／iPad Safari 与实体双面打印仍建议在发布后各做一次快速冒烟检查，因为 Chromium 仿真不能完全替代 WebKit 和具体打印机驱动。
