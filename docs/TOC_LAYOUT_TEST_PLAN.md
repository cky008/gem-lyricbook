# 打印目录排版回归测试计划

## 目标

本计划定义 G.E.M. LyricBook 打印目录的发布阻断标准。目录可以使用权重模型快速筛选候选版式，但最终是否单页、何时续页以及每页容纳多少内容，必须由浏览器在真实纸张尺寸中测量决定。测试和打印证据只使用公开曲目元数据或合成文本，不包含私人歌词。

## 真实数据基准

以 `src/data/setlists.json` 中的公开内置歌单为稳定基准：

- `builtin-iam-gloria-2-fixed-skeleton`：35 首固定流程，8 个章节；
- `builtin-shenzhen-composite-prediction-2026`：包含全部可选章节时共 72 首、12 个章节，其中固定流程 35 首、可选候选 37 首；
- 继续保留现有 34 首、5 个 Part 的合成基准，防止较短目录退化。

完整 72 首目录不得再因固定容量估算被提前切成 `62 + 10`。当真实测量确认安全时，A4、A5 和 A4 对折的 A5 逻辑页都应保持一个目录页，标题不得出现“（续）”。

## 版式候选顺序

每个目录先以完整内容依次尝试：

1. 单栏宽松；
2. 双栏标准；
3. A4 三栏紧凑，或 A5／对折双栏紧凑；
4. 只有所有完整页候选都不安全时，才查找当前页能够容纳的最大章节／歌曲前缀并创建续页。

权重模型只用于确定优先候选，不得直接作为最终分页结论。真实测量应等待字体可用和至少两个动画帧，再使用最终打印 DOM、实际列宽和最终字号。

## 验收矩阵

| 场景 | A4 | A5 | A4 对折逻辑页 | 必须检查 |
|---|---|---|---|---|
| 34 首／5 Part 合成基准 | 单栏单页 | 单页 | 单页 | 无“续”、顺序和链接正确 |
| 35 首固定流程 | 最宽松的安全单页候选 | 安全单页 | 安全单页 | 8 个章节完整且无重复 |
| 72 首完整可选歌单 | 安全单页，不得 `62 + 10` | 安全单页，不得稀疏续页 | 安全单页，不得稀疏续页 | 12 个章节、72 首、无“续” |
| 长目录标题与长歌名 | 计入真实换行高度 | 同左 | 同左 | 高宽、栏宽和页脚间距安全 |
| 超大合成目录 | 必要时续页 | 必要时续页 | 必要时续页 | 每页使用最大安全前缀，续页不稀疏 |
| 章节边界附近溢出 | 按歌曲边界拆分 | 同左 | 同左 | 不丢歌、不重复、章节续标明确 |

## DOM 几何断言

对每个逻辑页同时检查：

- page、inner、content 的 `scrollWidth/clientWidth` 与 `scrollHeight/clientHeight`；
- 目录标题、说明、章节标题、可选标签、换行后的歌曲条目及章节间距；
- 每一栏的实际高度和宽度；
- 正文底部到页码／页脚安全区的距离；
- `overflowPages` 必须为空，且不得依赖 `overflow: hidden` 掩盖失败。

完整单页候选只有在上述检查全部安全时才能被采用。分页候选必须用相同检查复核每一页；若某页不安全，应缩短该页前缀，而不是隐藏内容。

## 内容与导航断言

- 每个输入歌曲 ID 恰好出现一次，目录顺序与歌单顺序一致；
- 可选章节和固定章节的标签、顺序与类型保持不变；
- 页码在最终目录页数确定后重新计算；
- 每个目录链接指向对应歌曲的第一页；
- 续页只在真实测量证明完整目录无法安全单页容纳时出现；
- A4 对折的目录先按 A5 逻辑页完成，再参与骑马钉拼版。

## TDD 与浏览器证据

1. 先增加 72 首真实公开元数据回归，确认旧实现产生预期失败；红色状态不提交。
2. 保留权重模型的纯函数测试，并为候选顺序、最大安全前缀、条目唯一性和失败路径增加覆盖。
3. 在浏览器中分别生成 A4、A5 和 A4 对折，确认 `overflowPages=[]`。
4. 将三种版式保存为 PDF，用 `pdfinfo` 检查尺寸，用 `pypdf` 检查内部链接和目标，用 `pdftoppm` 渲染 PNG。
5. 目视检查目录首尾、章节交界、长标题、页码、页脚和对折首张印刷面。
6. 每次提交前运行完整 `npm run check`；任何裁切、缺失、重复、错序、断链或不必要续页都阻断发布。
