# 历史版本归档

此目录仅用于版本追溯、问题回归和数据迁移验证。日常使用与继续开发应以仓库根目录的 v5 源码项目为准。

## 目录

| 目录 | 说明 | 状态 |
| --- | --- | --- |
| `v1-initial/` | 首个响应式单文件、曲目核对、A4 与对折 PDF 模板 | 停止维护 |
| `v2-four-images/` | 四图曲目修订、现场补充和新歌彩蛋占位 | 停止维护 |
| `v3-pagination/` | 修复多空行、实际高度分页和小册裁切 | 停止维护 |
| `v4-multiversion/` | 多版本、双语和歌单排序单文件版 | 停止维护 |

## 迁移到 v5

1. 在旧版中导出 JSON 备份；
2. 打开 v5 网页；
3. 点击“导入我的歌词”；
4. 选择 JSON 并完成匹配；
5. 重新导出 v5 JSON 与含歌词离线 HTML。

v5 会把旧版单文本歌词转换为默认版本，并尽量保留多版本、翻译、收藏、熟悉标记和歌单。

## 注意

- 历史文件可能包含已经修复的分页缺陷；
- 历史 PDF 只是当时的空白模板，不代表 v5 当前打印结果；
- 此目录不包含用户上传的真实歌词 JSON；
- 不要在历史版本中继续长期录入数据。
