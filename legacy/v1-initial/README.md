# G.E.M. I AM GLORIA 歌词本（授权导入版）

## 最快打开方式

- **iPhone / iPad / Android / Mac / Windows：**直接打开 `GEM歌词本_单文件.html`。它把界面、曲目和程序全部打包在一个文件中，不依赖网络。
- **完整 PWA 版：**打开 `index.html`。若要安装到主屏幕并获得离线缓存，请先在本文件夹运行 `python serve.py`，再访问终端显示的地址。

## 已完成的内容

- 三张截图逐项收录：截图 1 共 43 个可见曲目、截图 2 共 85 个报批条目、截图 3 共 37 个曲目。
- 别名与版本归一：例如 `All About You` → `All About U`、`Find You` → `FIND YOU`，同时保留原图文字。
- 合并后共 **85 首独立歌曲**，另保留截图 2 中的非歌曲笼统项“其他”。
- 标记 2026 主歌单、返场、特别串烧、报批新增 / 待核实等状态。
- 响应式布局、明暗主题、字号调节、收藏、熟悉标记、沉浸阅读。

- A4、A5 与 A4 对折小册的彩色打印 / PDF 生成。

## 为什么没有预置完整网络歌词

完整流行歌曲歌词通常受版权保护。本项目没有从网络复制并打包未经授权的完整歌词。你可以导入自己购买、整理、获授权或有权使用的歌词文本。所有导入内容默认只保存在当前浏览器的 localStorage 中。

## 批量导入格式

使用 `lyrics-import-template.md`，按以下格式填写：

```text
## 喜欢你
第一段歌词……

第二段歌词……

## 光年之外
第一段歌词……
```

随后在网页中选择“导入我的歌词”即可。网页会按规范歌名与截图别名自动匹配。

## 打印

1. 在网页中点击“生成 PDF / 打印”。
2. 选择 A4、A5 或 A4 对折小册，选择当前歌曲、筛选结果或全部歌曲。
3. 系统打印对话框中可选择“保存为 PDF”。
4. A4 对折版已经按小册顺序拼版；通常应使用双面打印、短边翻转、100% 实际尺寸。不同打印机的翻转定义可能不同，先用 4 页测试最稳妥。
