## 粘贴歌词与自动保存

1. 在左侧选择歌曲。
2. 点“编辑”或“粘贴歌词”。
3. 把你有权使用的歌词粘贴进文本框。
4. 每次输入都会自动保存到当前浏览器的本地存储。

浏览器缓存可能被清理，且手机换浏览器、换设备后不会自动同步。完成一部分歌词后，建议立刻打开“批量导入 / 导出”，同时保存两份：

- **导出含歌词的离线 HTML**：歌词会直接封装到新网页文件里，之后在另一台设备打开也能看到。
- **导出 JSON 备份**：用于恢复歌词、收藏和熟悉标记，是最稳妥的备用副本。

`GEM歌词本_含歌词_日期.html` 可继续编辑，并可再次导出新的含歌词 HTML。

## 批量导入

可使用 `lyrics-import-template.md`，格式如下：

```text
## 喜欢你
第一段歌词……

第二段歌词……

## 光年之外
第一段歌词……
```

网页会按规范歌名和截图别名自动匹配。也支持导入本项目导出的 JSON 备份。

## 生成 PDF / 打印

1. 点击右上角“生成 PDF / 打印”。
2. 选择 A4 阅读版、A5 小本页或 A4 对折小册。
3. 选择当前歌曲、当前筛选结果或全部曲目。
4. 点击“打开系统打印 / 保存 PDF”。
5. 在系统打印窗口选择“保存为 PDF”。

A4 对折小册已自动拼版。实体双面打印通常选择 **短边翻转、100% 实际尺寸**；不同打印机定义可能不同，正式印刷前先测试 4 页。
