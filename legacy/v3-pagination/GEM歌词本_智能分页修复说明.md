# G.E.M. I AM GLORIA 歌词本（2026 智能分页修复版）

## 推荐文件

直接打开 **`GEM歌词本_2026智能分页修复版_单文件.html`**。它已把 Bootstrap、样式、89 个曲目页和全部程序封装在一个 HTML 中，不依赖网络，适合 iPhone、iPad、Android、Mac 和 Windows。

## 从上一版迁移已有歌词

1. 在上一版网页打开“批量导入 / 导出”。
2. 点击“导出 JSON 备份”。
3. 打开本修复版 HTML。
4. 点击“导入我的歌词”，选择刚才导出的 JSON。
5. 点击“读取并匹配”。

本版继续兼容 `gem-lyricbook-backup-v2`，歌曲 ID 与上一版一致，因此已有歌词、收藏和“已熟悉”标记都可恢复。虽然部分浏览器可能自动读取上一版的本地存储，仍建议先导出 JSON，避免换文件或清理缓存后丢失。

## 本次打印修复

- 不再按字符数粗略切页，而是按 A4 / A5 页面的实际可用高度测量后分页。
- “智能压缩多余空行”默认开启，只影响打印排版，不修改编辑器里的原始歌词。
- 当网页复制导致每一行歌词之间都多出一个空行时，会自动恢复为正常逐行排版。
- 普通段落之间的正常空行仍会保留。
- 自动在标准字号和紧凑字号中选择；只有确实能减少页数时才使用紧凑字号。
- A4 对折版会先完整拆成 A5 逻辑页，再进行小册拼版，因此超出第一页的歌词会进入续页，不再被直接裁掉。
- 续页显示 `2/2`、`2/3` 等编号，并保留页码。

极长的歌曲仍可能合理地占用 2 页或更多页面，以保证字号可读；修复目标是消除多余空白造成的异常页数和小册内容截断。

## 粘贴歌词与保存

输入会自动保存到当前浏览器。本地存储可能被清理，完成一部分后建议同时保存：

- **含歌词的离线 HTML**：歌词直接封装在网页中，可在其他设备打开。
- **JSON 备份**：用于完整恢复歌词、收藏和熟悉标记。

## 生成 PDF / 打印

1. 点击右上角“生成 PDF / 打印”。
2. 选择 A4 阅读版、A5 小本页或 A4 对折小册。
3. 保持“智能压缩多余空行（不改原歌词）”开启。
4. 点击“打开系统打印 / 保存 PDF”。
5. 在系统打印窗口选择“保存为 PDF”。

A4 对折实体打印通常选择 **双面、短边翻转、100% 实际尺寸、彩色**。不同打印机方向定义可能不同，正式印刷前先测试 4 页。
