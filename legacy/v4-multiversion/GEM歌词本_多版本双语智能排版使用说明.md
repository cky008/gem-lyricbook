# G.E.M. 歌词本：多版本、双语、智能排版与演出歌单排序

## 1. 从旧版迁移歌词

1. 在你目前正在粘贴歌词的旧版网页中打开“批量导入 / 导出”。
2. 点击“导出 JSON 备份”，把 `.json` 文件保存到“文件”App或电脑。
3. 打开新版单文件 HTML。
4. 点击“导入我的歌词”或“批量导入 / 导出”，选择刚才的 JSON，再点击“读取并匹配”。

旧版中每首歌的单一歌词会自动成为该曲目的“默认版”。收藏和“已熟悉”标记也会一起恢复。导入完成后，建议立刻再导出一次新版 JSON。

## 2. 为同一首歌保存多个版本

每首歌上方有“歌词版本”区域：

- “＋ 添加版本”：建立国语版、粤语版、英语版、现场版、不插电版等。
- “设为默认版本”：决定平时阅读和默认打印时使用哪一版。
- “复制版本”：以现有版本为底稿制作改词版或现场版。
- “阅读全部版本”：在同一个曲目页面连续查看该歌曲的全部版本。

同一歌曲只占一个曲目条目和一个目录条目。打印全部版本时，短版本会尽量合并在同一张物理页面；放不下时会在同一歌曲章节中自动续页，不会裁切或创建重复曲目。

## 3. 外语原文与中文翻译

每个歌词版本都有两个独立输入框：

- “原文 / 主歌词”
- “翻译 / 对照歌词”

可分别修改“原文标题”和“翻译标题”。当两边严格逐行对应时，开启“原文与翻译逐行对应”；A4 打印可左右对照，A5和对折小册默认上下分区，也可在打印设置中强制选择左右或上下。

## 4. 智能短行与双栏排版

原始歌词始终原样保存。打印时可选择：

- **自动**：先保留原换行；如果页数过多，再尝试把连续超短句合并为 `上一句 / 下一句`，必要时尝试左右双栏。
- **总是智能合并短行**：适合大量“一行只有几个字”的歌词。
- **严格保留原始换行**：完全不使用 `/` 合并。

单语歌词的栏数可设为自动、一栏或两栏。所有方案都按页面真实高度测量后再分页；A4对折版会先生成完整A5逻辑页，再做装订拼版，因此续页不会消失。

## 5. 默认版和全部版本的打印选择

“生成 PDF / 打印”中的“版本输出”支持：

- 每首仅默认版本
- 当前歌曲用当前版本，其余歌曲用默认版本
- 每首输出全部版本

因此可以维护一个包含所有版本的主歌词库，同时为现场打印只输出最常用的默认版本。

## 6. 正式演出歌单顺序

打开“演出歌单 / 排序”：

1. 新建歌单并填写名称，例如“深圳 2026-09-11 正式歌单”。
2. 将状态设为“正式 / 已核实”“现场记录”“预测 / 待核实”或“自定义草稿”。
3. 用 `## Part 1`、`## Part 2`、`## Encore` 等标题分段，每行粘贴一首歌。
4. 点击“保存并匹配歌单”，再点击“设为当前排序”。

程序会按已知 Part / Encore 的真实顺序排列。没有列入正式歌单的曲目会自动排在后面：先列返场候选，再列额外歌曲。歌单顺序会随 JSON 和含歌词离线 HTML 一起保存。

## 7. 最稳妥的保存方式

每次完成一批歌词后，同时保存：

- **含歌词的离线 HTML**：直接打开阅读，歌词、版本、翻译和歌单都封装在文件中。
- **JSON 备份**：用于恢复或迁移到后续新版。

浏览器的自动保存仅存放在当前浏览器本地；清理浏览器数据、换设备或换浏览器前，一定先导出文件。

## 8. A4对折打印

建议打印设置：

- A4 横向
- 双面打印
- 短边翻转
- 缩放 100% / 实际尺寸
- 开启背景图形和彩色打印

正式打印前先用一张纸测试正反面方向。
